How do you use it?
Here’s how:

1. Copy the YouTube or Spotify video link.

2. Open the "Top4Top.exe" application and paste the YouTube URL.

3. You might encounter an error on your first attempt; this is usually just a bug, so if it happens, simply try again.

4. Wait for the process to complete.

5. Once finished, copy the Top4Top link—and you're all set.
